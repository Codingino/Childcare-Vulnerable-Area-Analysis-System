# v2 운영·비용·개인정보

## 작게 운영하기

첫 기수 20~30명, 서버 가입 상한 50계정. 초대 코드는 없고 직접 가입합니다. 계정 수가 실제 서로 다른 보호자 수를 보장하지 않으며, 성인 여부는 자기 확인입니다. 실명 검증이나 휴대폰 인증을 구현했다고 안내하지 마세요. 신규 가입자는 '열린 이웃' 한 공동체의 승인 글을 볼 수 있습니다. 지역 매칭·개인 메시지는 없습니다.

성인 공동운영자·지도교사, 문의 창구, 종료일을 확정한 뒤 모집하세요. 실제 운영자 연락처를 앱의 안내 문구에 반영해야 합니다. 안내문은 구현에 맞춘 초안이며 법률 준수를 자동 보장하지 않습니다. 매일 게시물·답글·신고를 확인하고, 운영자 검토 시간을 모집 안내에 적으세요. 즉시 응답이 필요한 상담 창구로 사용하지 않습니다.

## 저장되는 것

| 위치 | 저장 내용 | 삭제 방법 |
|---|---|---|
| 현재 브라우저 | 부탁 카드와 마무리 기준·선택 응답 방식·작성/마무리 시각 | 내 공간에서 전체 삭제, 카드별 삭제, 앱 사용 시 90일 경과 카드 정리 |
| 서버 계정 | 가명 아이디, 무작위 ID, PBKDF2 비밀번호 해시, 가입일, 모임 | 계정 삭제 또는 보관기간 만료 작업 |
| 서버 서비스 | 글·답글·신고, 도움 응답·완료 상태 | 글/계정 삭제, 보관기간 작업 |
| 서버 연구 | 동의 상태, 주간 설문, 링크 방문 날짜, 생성 당시 동의한 요청의 연구 포함 상태, 선택 결과 문항 | 동의 철회·계정 삭제·보관기간 작업 |
| 로그인 | 해시한 세션 식별자, 계정 연결, 최대 14일 만료 | 로그아웃·계정 삭제·만료 |
| 인증 남용 제한 | 프로세스 비밀키로 HMAC 처리한 IP+경로 식별자, 시도 수, 15분 만료 | 이후 인증 요청에서 만료 정리 |

연구 문항은 심리 질환 진단용이 아니고 앱 사용 경험을 묻는 자체 문항입니다. 연구 CSV에 글 내용·계정 아이디·비밀번호·응답자 ID는 넣지 않습니다. 요청자 가명 ID와 시각이 있어 완전한 익명 자료가 아닙니다. 선택적 완료 피드백은 일반 이용자의 API 응답에도 반환하지 않습니다.

기기 카드는 계정별로 분리되지 않습니다. 같은 브라우저에서 다른 계정으로 로그인해도 같은 카드가 남습니다. 공유 기기에서 삭제하도록 안내하세요. 로그아웃과 서버 계정 삭제는 기기의 카드를 자동 삭제하지 않습니다. 공유 버튼을 누른 경우에만 사용자가 선택한 다른 앱으로 카드가 전달됩니다.

동의하지 않아도 카드·공동체를 사용할 수 있습니다. 연구 동의 이전의 도움 요청은 재동의하더라도 소급해 포함하지 않습니다. 철회 시 설문·링크·선택 완료 응답을 지우고 기존 요청의 연구 포함 표시를 끕니다. 다운로드한 CSV·백업도 운영자가 삭제해야 합니다.

## 운영 보안과 한도

- 로컬 시험은 `python start.py`. 공개 서버에는 HTTPS 프록시 + Gunicorn + 영속 SQLite 디스크를 사용합니다. `IEUM_HTTPS=1`로 Secure 쿠키를 켜세요. 설정이 꺼진 로컬 HTTP를 인터넷에 공개하지 않습니다.
- 새 계정은 비밀번호 해시, 브라우저 인증은 HttpOnly·SameSite 세션 쿠키입니다. JavaScript/기기 저장소에 로그인 비밀번호나 토큰을 넣지 않습니다.
- POST는 JSON과 `X-Ieum-Request: 1` 헤더를 요구하고 CORS를 허용하지 않습니다. 서버의 별도 계정 권한도 검사합니다.
- 인증 IP별 15분 동안 가입 5회, 로그인 15회 이후 제한. 로그인 실패도 횟수에 포함합니다. 프로세스 재시작 때 제한 키가 바뀌므로, 공개 운영에서는 앞단 요청 제한을 함께 설정합니다. 신뢰되지 않은 X-Forwarded-For를 코드에서 읽지 않으며 프록시 뒤의 여러 이용자가 동일 IP 제한을 받을 수 있습니다.
- 1인 1일 글 5개·답글 10개, 요청 본문 크기 상한, 매개변수 SQL을 사용합니다. 이미지·파일 업로드는 없습니다.
- 계정 복구·메일 발송·전화번호 인증·비밀번호 재설정 화면은 없습니다. 기존 v1 계정 전환은 운영자 CLI에서 본인 확인 후 수행합니다. 백업 없는 DB 삭제는 복구할 수 없습니다.
- DB는 단일 서버, Gunicorn workers 1 기준입니다. 이 코드를 여러 서버에서 하나의 로컬 DB처럼 운영할 수 없습니다.

## 검토할 때

`python server.py review` 결과에는 글 본문이 있으니 화면 공유·공개 로그에 남기지 않습니다. 아이 이름·상세 주소·전화번호·건강정보·광고·위험한 조언은 공개하지 않습니다. '들어주기' 요청의 경우 원치 않는 조언이 아닌지 봅니다. 자동 문구 필터가 모든 문제를 차단하는 구조가 아닙니다.

함께하기는 각자 아이를 돌보는 보호자 활동입니다. 아이 위탁·가정 방문·유료 돌봄 중개는 운영하지 않습니다. 48시간 이상 응답이 없는 요청은 확인하되, 운영자 답변을 일반 부모의 도움으로 섞어 발표하지 않습니다. 과도한 독려와 검토 지연도 운영일지에 적습니다.

## 보관기간·백업

`python server.py purge`를 매일 실행하는 스케줄 작업을 운영자가 설정합니다. 가입 90일이 지난 계정과 연결 데이터를 삭제합니다. 자체 자동 스케줄러는 없습니다. 이 절차와 별도 백업 삭제가 구성되기 전에는 '90일 뒤 자동 삭제된다'고 안내하지 않습니다.

기기 카드도 90일이 지난 내용은 앱 재실행 시 저장소에서 정리합니다. 앱을 다시 열지 않은 기기의 원격 삭제는 불가능합니다. 브라우저 데이터 삭제로 언제든 지울 수 있습니다.

서버를 끄거나 SQLite backup API를 이용해 일관된 백업을 만드세요. 실행 중인 WAL DB 파일 하나만 복사하는 방식은 피합니다. 백업은 원본과 동일한 보관·접근 기준으로 관리하고, 복구할 때 철회·삭제 요청을 재적용합니다. 모든 연구 CSV는 공개 저장소 밖에 둡니다.

## 돈과 운영 시간

직접적인 AI API·지도 API·영상 저장 과금이 없도록 텍스트·기기 카드 중심으로 만들었습니다. 서버·백업·도메인·트래픽은 별도입니다. 월 15,000원(서버·백업 10,000 + 도메인 환산 2,000 + 예비 3,000)을 **예산 상한 시나리오**로 둘 수 있지만 공급자의 실제 가격이거나 이 금액으로 운영 가능하다는 보장은 아닙니다. 계약 전 견적·세금·영속 디스크 비용을 확인하고 공급자 사용량/결제 알림을 설정합니다. 앱이 공급자 과금을 자동 차단하지 않습니다.

운영자가 하루 20분이면 월 약 10시간이며 모집·분쟁 대응은 추가입니다. 텍스트 저장 비용보다 관리 시간이 먼저 문제가 될 수 있습니다. 예산/시간 상한 80%에 도달하면 새 모집을 중단하고 운영 범위를 줄이세요.

초기 무료 → 사용성 확인 → 기관 운영도구 수요 인터뷰 순서가 적합합니다. 학교 예산·자발적 후원·기관 계약은 가능성일 뿐 확보된 수익이 아닙니다. 이용자 데이터 판매·정서 기반 타깃 광고·도움 요청 유료화는 목표와 충돌합니다. 현재 결제·광고 기능은 없습니다.

## PWA 범위

설치 화면, manifest, 192/512 아이콘, 서비스워커를 포함합니다. 서비스워커는 공용 화면 파일만 저장하며 `/api/`는 캐시하지 않습니다. 오프라인에서 게시·회원가입·연구 기록 저장이 되는 척하지 않고 오류를 표시합니다. 오프라인 전송 대기열·푸시 알림·앱스토어 배포는 없습니다. 현재 버전은 실제 기기 설치/브라우저 시각 검증을 완료한 상태가 아닙니다.
