# 이음 v2 — 오늘 하나 덜어내기

부모의 머릿속에 남은 일을 짧은 부탁 카드로 정리하고, 원하는 방식으로 도움을 연결하는 **설치 가능한 웹앱(PWA)** 입니다. 초대 코드가 없어졌습니다.

**상태:** Python 서버·모바일 앱 UI·PWA 구성·기기 카드·회원가입·연구 도구 구현. 공개 HTTPS 서버 배포, App Store/Play Store 등록, 실제 기기 설치 검증과 실사용 효과 연구는 아직 하지 않았습니다.

## 바로 실행

Python 3.11 이상에서 별도 패키지 설치 없이 로컬 실행:

```bash
cd ieum
python start.py
```

브라우저가 자동으로 열립니다. 열리지 않으면 **http://127.0.0.1:8000** 에 접속하세요. Windows에서는 `start.bat`을 더블클릭할 수도 있습니다. `python` 대신 `py` 명령을 사용하는 환경은 `py start.py`를 실행하세요. 종료는 실행 창에서 Ctrl+C.

**처음 화면은 가입 없이 사용합니다.** 부탁 카드를 정리하고 기기에 저장할 수 있습니다. 이웃 도움은 화면에서 영문·숫자·밑줄 아이디(3~24자)와 비밀번호(10~128자)로 가입하세요. 초대 코드를 발급하는 단계는 없습니다. 실명·아이 이름·상세 주소는 입력하지 마세요.

## 바뀐 점

- **머릿속 일 카드:** 시작 템플릿 → 원하는 도움 → 어디까지 부탁하는지 → 마무리 기준. 직접 수정·기기 저장·공유/복사·이웃에게 게시 가능.
- **응답 방식:** 들어주기 / 정보 정리 / 함께하기. 듣기형 요청은 조언 전 동의를 묻도록 안내.
- **앱 화면:** 하단 4개 메뉴, 모바일 다이얼로그, 큰 터치 영역, 내 기록, 공식 정보와 근거 설명.
- **PWA:** 홈 화면 아이콘·독립 실행 창·오프라인 기기 카드. 로그인/게시글/연구 API는 캐시하지 않음.
- **일반 계정:** 공개 자기 가입, PBKDF2 비밀번호 해시, HttpOnly 세션 쿠키, 로그아웃·만료·계정 삭제.
- **연구:** 기존 주간 설문 + 동의한 요청의 완료 후 응답 적합성·신경 쓰임 변화·추가 확인 부담(모두 선택).

마음 상태를 진단하거나 치료하는 앱은 아닙니다. 출석 보상·랭킹·무한 피드·시간 절약 추정 점수를 두지 않았습니다. 2/5/10분은 제안 시간이며 응답 속도나 실제 절약 시간을 보장하지 않습니다.

## 휴대폰에 앱으로 추가

휴대폰에서 접속할 **HTTPS 주소로 배포한 뒤**, 브라우저 메뉴 또는 공유 메뉴에서 '홈 화면에 추가/앱 설치'를 선택합니다. 지원 브라우저에서는 앱의 **내 공간 → 홈 화면에 앱 추가**도 사용할 수 있습니다.

컴퓨터의 `127.0.0.1` 주소는 그 컴퓨터용입니다. 휴대폰에 같은 주소를 입력해도 컴퓨터 서버에 연결되지 않습니다. 기기별 설치 메뉴는 다릅니다. 이 저장소를 GitHub Pages에 올리는 것만으로 Python 서버가 실행되지는 않습니다. APK/IPA 파일은 만들지 않았습니다.

서비스워커 업데이트 뒤에는 모든 앱 창을 닫았다 다시 열어 새 버전을 받습니다. 처음 온라인 접속을 마친 뒤에만 오프라인 화면을 쓸 수 있습니다. 기기 카드는 현재 브라우저 저장소에 남아 로그인 계정 간 분리되지 않으므로 공유 기기에서는 **내 공간 → 이 기기의 카드 모두 삭제**를 사용하세요.

## 예전 버전에서 업데이트

기존 `data/`는 덮어쓰거나 삭제하지 말고, 서버를 끈 상태에서 별도 백업한 뒤 코드 파일을 교체하세요. 시작 시 v1 DB에 필요한 열과 테이블을 추가합니다. 기존 글·모임은 유지됩니다. 예전 초대 코드 로그인은 더 이상 지원하지 않습니다.

새로 만든 시험 계정이라면 화면에서 새 계정으로 가입하면 됩니다. 기존 계정과 글을 이어 쓰려면 운영자가 DB의 해당 member ID를 확인하고 다음을 실행합니다. **본인 계정임을 기존 운영 절차로 확인한 후** 적용하세요.

```bash
python server.py migrate-account --member EXISTING_MEMBER_ID --username my_parent_id
```

비밀번호는 터미널에서 숨김 입력합니다. 이 명령은 기존 계정의 모임과 글을 유지합니다. 새 가입 계정은 '열린 이웃' 공동체로 들어가며 기존 모임과 자동 합쳐지지 않습니다. 원래 코드의 토큰 열은 DB 호환을 위해 남아 있으나 로그인에 쓰지 않습니다.

## 운영자 검토

글·답글은 검토 후 다른 사람에게 공개됩니다. 아직 관리자 웹 화면은 없고 아래 명령으로 운영합니다.

```bash
python server.py review
python server.py approve --table posts --id 1
python server.py approve --table replies --id 1
python server.py hide --table posts --id 1
```

`1`은 실제 ID로 바꾸세요. '들어주기'에 원치 않는 조언이 달렸는지, 연락처·아이 정보가 포함됐는지 확인합니다. 신고는 글을 재검토 대기로 바꿉니다. 운영자의 부재 시 응답이 지연될 수 있으며 실시간 상담 서비스가 아닙니다.

## 연구 CSV 및 분석

```bash
python server.py export --output data/research.csv
python server.py export-help --output data/help.csv
python analyze.py data/research.csv --help-csv data/help.csv
python context.py data/context.csv
python server.py purge
```

지역 파일 형식은 `docs/context-template.csv`. 실제 집 주소는 필요하지 않습니다. 현재 앱의 직접 가입자는 하나의 공동체이므로 지역 비교 데이터가 자동 생기지는 않습니다.

CSV는 가명 연구 원본이며 GitHub에 공개하지 않습니다. 글 본문·아이디·비밀번호·도움 제공자 ID는 연구 CSV에서 제외합니다. 동의 철회 후 과거 요청은 연구에서 계속 제외되고 선택적 완료 응답도 삭제됩니다. 기기 카드 내용은 연구 서버로 자동 전송되지 않습니다.

## 실제 서버 실행

영속 디스크와 HTTPS 프록시가 있는 서버에서 사용합니다. 로컬 개발용 서버를 인터넷에 직접 노출하지 마세요.

```bash
python -m pip install -r requirements.txt
python -m gunicorn --bind 127.0.0.1:8000 --workers 1 --threads 4 --timeout 30 wsgi:app
```

운영 환경변수: `IEUM_DB`는 영속 DB 경로, `IEUM_HTTPS=1`은 Secure 세션 쿠키 활성화입니다. 운영에서는 반드시 HTTPS와 Secure 설정을 함께 적용합니다. 공급자 배포는 아직 수행하지 않았습니다. 비용 상한·모더레이션·보관기간 작업은 [운영 안내](docs/OPERATIONS.md)를 확인하세요.
